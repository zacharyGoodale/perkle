These are the exact instruction/configuration variants used in rounds 00–13. Numbering has gaps because some rounds evaluated existing variants, thresholds, or shared candidates. Round 12 no-history control is the selected baseline; round 13 is the rejected clear-rubric arena synthesis. These configurations are preserved for inspection, not recommended alternatives.
